## 结构

- 宏结构 Split Studio：预览在左，参数在右，两栏等高；窄屏上下堆叠，预览在上。
- 两栏对齐：`.shell` 用 `align-items: stretch`，左卡与面板同高；`fieldset` 撑满、下载按钮贴面板底，右栏多出的高度全部落在按钮上方，不出现半截空白。
- 顶栏用上下布局的页面框架（content/layout/tdesign.tencent.com--page-framework.md:54）。工具只有一个任务，不做整站导航；页头只留「全部工具」回入口页和 GitHub 图标两个入口。
- 页面同一时刻只留一个主按钮：无图时是「选择图片」，有结果后换成「下载透明 PNG」，其余按钮用描边次级样式；切换按钮用 `aria-pressed` 显式 true / false（content/components/inclusive-components.design--toggle-button.md:179-181）。
- 删掉原版的 01 / 02 / 03 编号步骤卡，拍摄要求只留图文对照四组，每对下面一行做法。原「上传」那段独有信息压成指南末尾一句。

## 自测

- 配色框架：主色一套蓝，hover 加深一档（Blue7 → Blue8），选中用主题色实填。没有第二种色相参与界面。焦点环统一为墨色 2px，偏移 2。
- 视觉层级：28 / 20 / 14 三档，最大元素只有页面标题一处。
- 布局模式：纵向间距由父级一处的 gap 给；两栏用 grid 的 1fr 与固定栏宽，窄屏换单列，不为每档宽度单独写一套。
- 动效落地：有状态变化的组件逐个列了触发与动的属性，见下。

| 组件 | 触发 | 动的属性 | 时长与曲线 |
| --- | --- | --- | --- |
| 主按钮、次按钮 | 悬停、按下 | 颜色、1px 位移 | 200ms standard |
| 开关 | 勾选 | 底色、圆点位移 | 200ms standard |
| 下拉 | 悬停 | 边框色 | 200ms standard |
| 视图切换 | 切换 | 底色、文字色 | 200ms standard |
| 拖放区 | 拖入 | 边框色、底色 | 200ms standard |

## 验收实测

- 横向溢出：320 / 375 / 767 / 1280 四档实测 `scrollWidth === clientWidth`，越界元素 0 个。
- 对比度（脚本实算，非目测）：正文 90% 黑对白 17.58:1、对灰底 16.00:1；次要文字 60% 黑 5.74:1 与 5.58:1；白字对主按钮 6.54:1、hover 9.40:1；错误红 6.31:1 与 5.69:1；控件边框 3.41:1；焦点环墨色 17.58:1。
- 交互真跑：上传 02 号案例图得 284×284 px、红色 19.3%、183 ms；透明 / 白底 / 原图三种视图切换正常；灵敏度 20 与 90 分别得 20.5% 与 36.3%，参数确实改变结果。
- 案例图背景同步换掉：四张 compare.png 由 `cases/make-compare.py` 重新生成，旧版的 #f7f5ef 纸色背景换成白底加灰白棋盘格的同尺寸画板，标签 15px #666；输入图先按红色主体外扩 8% 裁边，让宽幅手机照里的章和其他三张同尺度。
- 空态换成真实示例：132px 棋盘格方块内放 02 号案例的输出章（112px），下方「用示例图试试」走 `fetch` 取 input、转 `File` 走同一套 `loadFile`，实测得 284×284 px、红色 19.3%、113 ms。
- 案例卡可试用：四张卡带 `data-src`，点图片或「用这张试试」载入对应 input 并滚回工作台；实测载入 01 号手机拍样例得 407×404 px、红色 27.6%、134 ms。
- 案例说明从卡外一行提到卡内三行：名称 14px 600、备注 12px 次要色、右侧 14px 蓝色文字按钮；整卡 hover 与 `:focus-within` 时图片描边转主色。
- 键盘顺序实测：GitHub 图标 → 用示例图试试 → 选择图片 → 增强开关 → 灵敏度 → 颜色 → 四张案例 → 页脚链接，全部可见焦点。
- 动效实测：开关 `transition: background-color 0.2s cubic-bezier(0.38, 0, 0.24, 1)`，与 `--dur-base` / `--ease-standard` 一致。
- 断点复测：1421 / 1261 / 749 / 256 四档 `scrollWidth === clientWidth`，无横向溢出。
- 两栏对齐实测：1440 档预览卡与参数面板 `top` 127、`bottom` 670 完全相同（高 566）；预览区最小高度降到 `clamp(360px, 46vh, 520px)`，右栏自然高度 543，拉伸差只有 23px。
- 状态行拆成三个 `span`（尺寸 / 红色占比 / 耗时）各自 `nowrap`，320 档整体换行，不再把「ms」拆到下一行。

- 统一复测（2026-11-16）：320 / 375 / 414 / 767 / 768 / 991 / 992 / 1280 八档无页面横向溢出；行高按字号加 8 普查 0 处违例。页头 12 / 24（窄屏 12 / 16），页名收到 20 / 28；页脚改深墨底、32 / 24 内边距，白字说明 7.4:1。
- 串联：页头品牌与「全部工具」都回 `/ohmystamp/`，页脚「另一件工具：印章生成」直接去 `/ohmystamp/1/`；本地路由实测三页往返都成功。
