# 设计缺口

本次改版按 UISpecs 的 TDesign 基准规范取值，下面是规范没覆盖、或原文与实测有出入的地方。

## 库内没有原文的维度

| 维度 | 处理 | 依据 |
| --- | --- | --- |
| 圆角 | 控件 4px、卡片 8px，整站两档 | 库内无通用圆角规范，按缺口规则派生 |
| 控件高度 | 按钮、下拉、滑杆行统一 40px；紧凑按钮与分段控件 32px | 库内组件文章只给 API，不给尺寸，派生 |
| 分隔线宽 | 1px | 库内只给颜色不给线宽，派生 |
| 透明棋盘格 | 20px 方块，Gray2 与白色交替 | 表示透明底的通用画法，非规范值 |

## 原文与实测的出入

- TDesign 直接说常用文字对比度都大于 4.5（`content/color/tdesign.tencent.com--color.md:91`），但它自己的 Red6 只有 4.32:1（`同文件:52`）。错误文字因此换 Red7，实测 6.31:1。
- 字体篇自述字色满足 4.5（`content/type/tdesign.tencent.com--fonts.md:96`），其中 40% 与 26% 两档实测只有 2.8:1 上下，只用于禁用与装饰，不承担可读文字。

## 没覆盖到的

- 只做了亮色一套，没有暗色主题。TDesign 有暗色篇，本次改版范围不含。
- 图标只用了品牌标记与 GitHub 两个内置 SVG，没有引入 TDesign 图标库。
- 页脚只有一行声明与一个 MIT 链接，不做链接区；入口页的导航由「全部工具」一个链接承担。
