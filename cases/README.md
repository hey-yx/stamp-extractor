# 案例

四组输入与提取结果，默认设置：自动增强开、灵敏度 50、正红。对比图左边是输入，右边是透明底提取结果。

| 案例 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| 01 手机拍的纸面章 | 1280×582 | 406×404 | 真实照片，原图提取后对字号和编码打码 |
| 02 合同专用章 | 305×306 | 284×284 | DB4403 官方案例，圆章无星 |
| 03 财务专用章 | 305×306 | 284×284 | DB4403 官方案例，圆章无星 |
| 04 外资合同专用章 | 433×290 | 428×286 | DB4403 官方案例，椭圆章，输出保持椭圆比例 |

`cases.json` 记录每个案例的路径和输出尺寸。

## 素材来源

- 01：真实盖章照片。提取跑的是未打码原图，导出后再打码；展示用的输入图同样打了码，原图不公开。
- 02 到 04：DB4403/T 383.6-2023 附录 A 官方案例裁切，占位名称「深圳市某某」。

## 输出规则

按章体实际像素贴边裁切，只留 1px 透明边。圆形章输出正方形，椭圆章保持原比例，不补白、不放大。
